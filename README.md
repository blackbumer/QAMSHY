# QAMSHY: Ұлы Даланың құпиясы

Интерактивная браузерная игра на казахском языке для учеников 7–8 классов.

## Как запустить

Откройте файл `index.html` двойным щелчком. Игра не требует установки Python, регистрации или API-ключа.

Для локального сервера можно выполнить:

```powershell
python -m http.server 8000 --directory dist
```

Затем открыть `http://localhost:8000`.

## Что реализовано

- 9 последовательных миссий;
- исторические вопросы с объяснениями;
- сборка қамшы и виртуальная мастерская;
- словесные и визуальные головоломки;
- конструктор собственной цифровой қамшы;
- «Ұлттық мұра ұпайы», достижения и секретный уровень;
- финальный статус «Ұлы Дала мұрасын қорғаушы»;
- сохранение прогресса в браузере;
- адаптивный интерфейс для компьютера и телефона;
- кнопка включения и выключения звука.

## Структура

- `dist/index.html` — страница игры;
- `dist/styles.css` — оформление и адаптивность;
- `dist/app.js` — логика миссий;
- `dist/assets/` — иллюстрации.

Для школьной презентации достаточно скопировать всю папку проекта на флешку и открыть корневой `index.html`.
